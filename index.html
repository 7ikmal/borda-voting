Apa itu Borda Count?

Borda Count adalah metode perankingan di mana pemilih memberi peringkat semua kandidat. Jika ada k kandidat, peringkat 1 mendapat k poin, peringkat 2 mendapat k-1, ... sampai peringkat k mendapat 1 poin. Metode ini cocok untuk memilih kandidat kompromi.

Mulai Voting Lihat Hasil
Catatan keamanan: Ini prototipe edukasi — penyimpanan lokal (localStorage) dan bukan sistem e‑voting audit.

Fitur

  • Input peringkat pemilih (sortable & keyboard accessible).
  • Skor Borda otomatis (skala n→1).
  • Tampilan rekap tabel, matriks peringkat, grafik (Chart.js), export CSV, reset data.

Konfigurasi Cepat

Edit /js/config.js untuk mengganti nama organisasi & kandidat.

Prototipe — untuk tujuan pendidikan. Lisensi MIT. Lihat README.md untuk panduan hosting di GitHub Pages.
